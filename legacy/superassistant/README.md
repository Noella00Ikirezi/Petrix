# SuperAssistant

Assistant de productivité local avec IA pour la cybersécurité.

## 🎯 Fonctionnalités

- **Gestion de tâches intelligente** avec priorisation IA
- **Agenda intégré** avec timeboxing et Pomodoro
- **Gestion de projets** avec Kanban
- **Assistant IA** pour emails et documents SMSI
- **Base de connaissances** pour templates et solutions
- **100% local** - vos données restent privées

## 🚀 Installation rapide

```bash
# Installation automatique
./setup.sh

# Démarrage
./start.sh
```

## 📋 Prérequis

- Python 3.10+
- Node.js 18+
- Clé API Anthropic (Claude)
